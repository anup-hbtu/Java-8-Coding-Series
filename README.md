## 🎯 About This Repository

This repository contains my **daily Java 8 coding practice** focused on
backend development and product-based company interviews.

The objective is not simply to solve problems, but to understand the concepts,
patterns, and techniques behind each solution.

### What this repository focuses on

- Java 8 Stream API
- Lambda Expressions
- Functional Interfaces
- Functional Programming
- Collections
- Filtering and Mapping
- Sorting and Searching
- Reduction
- Grouping and Partitioning
- String processing
- Employee-based real-world problems
- Nested collection processing
- Interview-oriented coding patterns
- Time and space complexity
- Common interviewer follow-up questions

The problems are organized progressively from **beginner-level Stream operations**
to **advanced real-world Stream API problems**.

# 🧰 Java 8 Stream API Reference

## Stream Pipeline

```text
Source
  ↓
Stream
  ↓
Intermediate Operations
  ↓
Terminal Operation
  ↓
Result
```

Example:

```java
List<Integer> result = numbers.stream()
```

# 🧩 Common Stream Patterns

## 1. Filtering

```java
numbers.stream()
       .filter(n -> n % 2 == 0)
       .collect(Collectors.toList());
```

**Pattern:**

```text
Collection
    ↓
stream()
    ↓
filter(condition)
    ↓
collect()
```

---

## 2. Mapping

```java
names.stream()
     .map(String::toUpperCase)
     .collect(Collectors.toList());
```

**Pattern:**

```text
Input
  ↓
map()
  ↓
Transformed Output
```

---

## 3. Numeric Sum

```java
int sum = numbers.stream()
                 .mapToInt(Integer::intValue)
                 .sum();
```

---

## 4. Numeric Average

```java
double average = numbers.stream()
                        .mapToInt(Integer::intValue)
                        .average()
                        .orElse(0.0);
```

---

## 5. Maximum

```java
int max = numbers.stream()
                 .mapToInt(Integer::intValue)
                 .max()
                 .orElse(0);
```

---

## 6. Minimum

```java
int min = numbers.stream()
                 .mapToInt(Integer::intValue)
                 .min()
                 .orElse(0);
```

```java
List<Integer> result = numbers.stream()
                              .distinct()
                              .collect(Collectors.toList());
```

```java
Map<Integer, Long> frequency = numbers.stream()
```

```java
Map<String, List<Employee>> result =
```

# 🧠 Important Interview Concepts

## map() vs mapToInt()

```text
map()
  ↓
Stream<Integer>

mapToInt()
  ↓
IntStream
```

`mapToInt()` is particularly useful for numeric operations such as:

```text
sum()
average()
min()
max()
```

---

## sum() vs reduce()

```text
sum()
  ↓
Specialized numeric aggregation

reduce()
  ↓
General-purpose reduction
```

Example:

```java
int result = numbers.stream()
                    .reduce(0, Integer::sum);
```

---

## max() and Optional

`Stream.max()` returns an `Optional<T>` because the Stream may be empty.

```java
Optional<Integer> max =
        numbers.stream()
               .max(Integer::compareTo);
```

For primitive streams:

```java
OptionalInt max =
        numbers.stream()
               .mapToInt(Integer::intValue)
               .max();
```

---

## average() and OptionalDouble

```java
OptionalDouble average =
        numbers.stream()
               .mapToInt(Integer::intValue)
               .average();
```

This is why `average()` should not be directly assigned to a primitive `double`
without handling the optional result.
